# Remote Pi Readable

Personal Android build with terminal-inspired blue-gray dark surfaces, pale foregrounds, cyan/teal accents and bundled **FiraMono Nerd Font** from the local terminal setup. Regular, Medium and Bold faces work offline; italic is deliberately synthesized by Flutter (no bundled italic face). Inter branding and platform sans-serif body text are unchanged. Light theme and existing theme/text-size choices remain available.

## Session identity

- Session labels prefer the current verified desktop manual name, then the saved mobile alias when the desktop name is reset, invalidated or unavailable, then the working-directory basename (Unix or Windows) and routing/device fallbacks, followed by the available path and session/room context. Duplicate project names remain separate rows with session names and room discriminators; full original paths remain available in session details.
- **Working**, **Online · idle**, **Reconnecting**, and **Offline** describe existing observed connection/working facts, not inferred agent roles or last activity. Models are secondary context, not project identity.
- Home titles, avatars, navigation hints and chat headings use the same plain-text label resolver. **Mobile alias** edits only the saved fallback; it cannot override a current verified desktop name. Desktop renames update the visible label without overwriting the alias; clearing the alias uses the project/routing fallback when no desktop name is available. Desktop display authority is ephemeral, never a saved alias or routing/history identity; offline/cold caches use their mobile alias and fallback. Historical code26/code27/code28 packaged the earlier alias-first naming; this desktop-first presentation correction is source-only until a subsequent build/device activation. Corrected code25 did not include naming. Actual compatible Relay/producer rollout and phone rename/reset acceptance remain separate pending gates. **No messages available** means the visible history is empty; being online does not guarantee content. A short reverse chat naturally bottom-aligns; blank space alone is not a paint failure.
- Foreground resume requests presence and rooms for existing paired subscriptions on a connected relay socket. The relay suppresses unchanged snapshots: after heartbeat degradation, only a current paired-target Pong can restore the exact previously-live active room locally removed by this client, then request discovery for changed registry state. Selection/channel/subscription changes, explicit room end and authoritative snapshot invalidate that recovery authority. Arbitrary messages and unknown/cache-only rooms never gain Online. Inner transport rejects other senders/wrong rooms and queued old-selection payloads; other paired PCs' discovery controls remain unaffected. Offline cached rooms remain visible. Pi processes must still register their rooms; this does not change startup consent.

## Chat controls (published in code28)

- Commands, edit diffs, and fenced assistant code start collapsed. Assistant prose remains visible. Tap the title disclosure header to disclose details; the header reports expanded state to accessibility services. Tool statuses use both colored icons and text; code examples show language and exact line count, not execution status.
- Expanded command/code/result/error text wraps to phone width by default. **Scroll** opts into horizontal scrolling; **Wrap** returns to wrapping. Copy/wrap controls sit separately below the expanded title so narrow screens and large text retain usable titles/statuses. These controls do not toggle disclosure. Composite codemode cards keep nested preview/Original Script frames at the available phone width even under top-level Scroll. Their open and Wrap/Scroll states survive outer Wrap → Scroll → Wrap; returning to outer Wrap resets horizontal offset. Only these composite outer viewports opt into stable scroll-body ancestry; existing CodeViewport defaults are unchanged.
- Known Bash/PowerShell commands (including namespaced tool names) render the actual command string even when timeout/other metadata is present. Codemode retains its exact code string; write shows its content with a language inferred from the file extension. Review separates **Command / Script / Source**, **Output**, and **Error**. Newlines, indentation, quoting and intentional literal `\n` remain unchanged: no formatter, interpreter or global escape replacement is used. **Copy command** copies only the exact original command. **Copy source** does the same for scripts/write content. Optional **Details** exposes original arguments plus complete result/error, with **Copy full details**. Unknown/malformed shapes retain the raw safe fallback; actual JSON output remains Output. Styled edit hunks and raw payload remain available.
- Supported codemode scripts lead with **Static embedded source · not execution records**: separately disclosed Bash/PowerShell commands, edit before/after strings and write contents. **Copy decoded embedded string** copies that literal's value; **Copy source** still copies exact outer JavaScript, independently available under **Original Script**. The bounded static dialect accepts only semicolon-terminated direct `tools.bash/powershell/edit/write({...})` calls (optional `await` / `text(...)`), static objects/arrays/literals, spaces/tabs/line endings and closed comments. Line comments terminate at LF, CR, U+2028 or U+2029 (including CRLF), so unsupported following calls cannot be swallowed. Single/double quoted strings decode exactly one supported escape layer (`n/r/t/b/f/v`, quotes/backslash, two-digit hex and four-digit Unicode); runtime literal `\n` and Windows paths stay literal. No templates, concatenation, arbitrary expressions, regex or unknown calls are evaluated or searched for argument keys. Any unsupported/malformed script or shape declines all previews and retains exact Script; limits are 24k source, nesting16, 512 values and 32 previews. Unknown source languages retain the original view; embedded language inference uses the Unix/Windows basename and requires an actual extension; unknown extensions, extensionless language-name files and dots only in directories stay plain text.
- Readable **Output** is supported for known Bash/PowerShell result wrappers (protocol-decoded Map or JSON String), and for known codemode's complete `Script completed / Wall time / Output` envelope with ordered `==> text n/total <==` sections or a single markerless wrapper. `Output:` is followed by exactly one LF plus an optional second LF. Section markers must start immediately at that captured boundary. With zero markers, the entire remainder must start exactly with `{` and validate as the same wrapper; no leading padding, third LF, garbage/prose, malformed marker or parsed fragment is accepted. Internal pretty JSON and legal trailing JSON whitespace remain supported. Prefix bytes are preserved exactly. Wrappers must have exactly `output` (string), `truncated` (boolean), `exit_code` (integer), and nonnegative finite `wall_time_seconds`. Compact, pretty/spaced and equivalent JSON escaping are accepted; duplicate top-level keys (including escaped-equivalent names) are rejected by a bounded scalar-property scan after JSON/schema validation. Quoted output tokens are skipped whole, not searched for keys. Decoded newlines/indentation appear with all three metadata fields under **Result metadata**; `truncated:true` stays visible and is not called complete output. Plain acknowledgements, other JSON, malformed/incomplete/unknown wrappers, nested unsupported data, prose and Python repr remain intact. Input is bounded to 96k and codemode to 32 ordered sections. Section headers/order are unchanged; they are not matched to static source calls or turned into tool statuses. **Original Output** / **Copy original output** retain exact original result text (or lossless pretty serialization of an already-decoded Map); **Details** includes full original args/result/error. This is presentation only: no transport, tool execution, or inferred child telemetry changes.
- Disclosed source and assistant/subagent code fences share theme-aware selectable syntax colors. Known shell, PowerShell, JS/TS, Python, Dart, JSON, CSS, XML/HTML and YAML aliases are supported. Unknown languages, parser failures, or source over 24,000 UTF-16 code units remain exact plain monospace. Highlighting is lazy (collapsed source is not parsed), with one bounded cached parse tree per mounted source widget, not an unbounded global cache.
- Every session starts in Main with a fixed bottom **Sub-Agents / Main-Thread** toggle and an explicit empty agents view. The agents composer is hidden/disabled, so messages cannot accidentally appear directed at a child. View, scroll, disclosure and wrap choices survive ordinary updates/switches within the mounted peer/room; changing peer/room starts fresh.
- Single-agent launch cards disclose actual assignments and available output. Workflows/parallel calls remain one launch accordion listing known assignments plus **Shared workflow output**, not invented per-child cards or duplicated results. Known Markdown/code fences use the same individually collapsible code renderer. **Expand all / Collapse all** still changes the persisted **Collapse subagents** preference.
- Opening a tool, code or agent accordion aligns its original heading below the real session toolbar/viewport once per expansion, with the body underneath. The heading and its copy/wrap/collapse controls stay in normal card flow and scroll away naturally; no duplicate, overlay, hidden original or heading-height clipping. Nested disclosures align independently. Updates do not realign. Short edge disclosures receive bounded viewport-derived extra scroll room only while needed by that expanded disclosure; collapse reconciles the extent.
- Main messages stay visible, with newest output at the bottom. **Latest** returns to the bottom. Explicit expansion/collapse and Wrap/Scroll choices survive lazy-list scrolling and ordinary updates; untouched default collapsed rows are not pinned in memory. State is scoped by peer/room and message identity, not a global cache.
- **Hide tool calls in chat** hides tool/agent contents, not the bottom toggle; Sub-Agents then shows its empty state.
- The connection supplies flattened launch-call text, not structured live child transcripts, nested tool events or asynchronous completion. Completed calls say **Call returned**, not child completion; existing explicit detached receipts remain **Launched**. Assignments are not live progress; action/control calls remain normal tool cards. No output files are fetched and no hierarchy/commands are inferred from prose. True per-child nested telemetry is an open transport/package gate, confirmed by `../.orchestration/results/72-subagent-data.md`.
