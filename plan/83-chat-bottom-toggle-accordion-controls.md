Not compact-density/10dp type/14dp icon/30dp button. Reachable above composer/footer; responsive at320dp and2x text with IME, no clipping/content obstruction. No forced bottom scroll on updates while reading earlier output.
5. **Double tap expanded surface to collapse:** usable from body/surface of long tool/code/agent disclosures, not solely a hidden offscreen header. Existing single-header toggle still works. Collapse changes owning disclosure once; innermost eligible nested disclosure wins, not simultaneous outer/inner collapse. Use non-interactive card surface/padding gesture areas where selection wins; document exact supported hit surfaces rather than falsely claim text double taps collapse when selection legitimately consumes them. Immediate follow-up reopen/updates work; reconcile edge extent without jumping to another message.
6. **Copy output beside Done:** add inline icon action adjacent to status on tool accordion headers whenever output exists; tooltip/semantics **Copy output**. Copy only that accordion's output, never command/source/other accordion text; prefer existing lossless readable result normalization, with exact raw fallback for unknown envelopes. Preserve whitespace/newlines and show complete-vs-truncated metadata honestly. No result implies omitted/disabled action, not invented output. Existing command/source copy remains separately labelled/available. Action doesn't expand/collapse, change Wrap/Scroll, scroll or send. 320dp/2x status/title/copy layout has >=48dp tap hit target without hiding Done; wrap responsibly, no text shrinking/ellipsizing all useful controls.
7. **Focused validation:** actual production ChatPage/tool/code/agent widget tests for all changes, real geometry/semantics and clipboard expectations. Add old-baseline failing regressions where practical, preserve failures honestly. Cover normal+reverse/nested long+short edge lists, lazy state/tab replacement, room/dispose, light/dark,320dp/2x and keyboard, retained Main draft and reactive Session-info lifetime regressions. Formatter/scoped analyzer with cached tools/no pub get; affected suite only, no redundant historical broad suite. Capture bounded host-rendered production UI PNGs if practical; distinguish test/font/transport fixture limits from installed APK/real phone acceptance.
